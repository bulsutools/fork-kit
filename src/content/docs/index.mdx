## One-click templates

Skip the fork entirely — generate a repo from a clean mirror of upstream
`main` (no campus config baked in):

- [room-tba-template](https://github.com/new?template_name=room-tba-template&template_owner=bulsutools) — **Use this template**
- [website-template](https://github.com/new?template_name=website-template&template_owner=bulsutools) — **Use this template**

Template repos have no `upstream` remote; add one if you want
[syncs](/concepts/keep-in-sync/).
